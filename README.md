# Alaya-Vijnana
A wireless split ortholinear column-staggered keyboard that uses the Framework keyboard control board.

This is an adaptation of [Alaya-Vijnana-v2](https://github.com/OGBlackDiamond/Alaya-Vijnana-v2) to use Framework's wireless keyboard hardware, made under their developer program.

## What's an Alaya Vijnana?
The Alaya Vijnana system is a control interface to connect a Gundam pilot to their machine. I'm a nerd, and I name all of my computers after mobile suits (usually Gundams). Since a keyboard is how I interface with my computer, I felt a Gundam control system was an apt name.

For more information, visit [the IBO wiki](https://g-tekketsu.fandom.com/wiki/Alaya-Vijnana_System).
